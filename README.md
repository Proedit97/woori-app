# 우리기록 · 설치형 커플 기록 앱 (PWA)

Chrome의 "앱 설치"로 PC·휴대폰 바탕화면에 아이콘이 생기는 웹앱이에요.
두 사람이 같은 공간에 디데이, 맛집, 문화생활, 앨범, 가계부, 일기, 지도, 캘린더, 습관, 버킷리스트를 함께 기록해요.

- `firebase-config.js`를 비워두고 열면 **체험 모드**예요. 이 기기에만 저장돼요.
- Firebase를 설정하면 **로그인과 초대코드로 커플 연결**이 되고, 기록이 실시간으로 함께 보여요.

---

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 화면과 기능 전부 |
| `firebase-config.js` | ★ 내 Firebase 설정값을 넣는 곳 |
| `firestore.rules` | ★ 데이터 보안 규칙 (두 사람만 읽고 쓰게) |
| `fb.js` | Firebase SDK (수정 안 함) |
| `maps.js` | 세계·한국 지도 데이터 |
| `sw.js`, `manifest.webmanifest`, `icons/` | 설치·오프라인용 |
| `firebase.json` | Firebase Hosting으로 배포할 때만 사용 |

## 1. Firebase 프로젝트 만들기 (무료)

1. https://console.firebase.google.com 에 Google 계정으로 들어가요.
2. **프로젝트 만들기**를 누르고 이름을 적어요. Google 애널리틱스는 꺼도 돼요.
3. 결제 수단을 등록할 필요 없는 **Spark(무료) 요금제** 그대로 쓰면 돼요.

## 2. 웹 앱 등록 → 설정값 붙여넣기

1. 프로젝트 첫 화면에서 **`</>`(웹)** 아이콘을 눌러 앱을 등록해요. 닉네임은 아무거나 적으면 되고, Hosting 체크는 안 해도 돼요.
2. 화면에 나오는 `firebaseConfig = { ... }` 안의 값을 복사해요.
3. `firebase-config.js`를 메모장으로 열고, 같은 이름 칸에 붙여넣고 저장해요.

```js
window.FIREBASE_CONFIG = {
  apiKey: "AIza....",
  authDomain: "my-couple.firebaseapp.com",
  projectId: "my-couple",
  storageBucket: "my-couple.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcd..."
};
```

> 이 값은 앱에 그대로 들어가는 공개용 값이라 외부에 보여도 괜찮아요. 실제 보호는 4단계의 보안 규칙이 해요.

## 3. 로그인 방식 켜기

1. 왼쪽 메뉴에서 **빌드 → Authentication → 시작하기**를 눌러요.
2. **로그인 방법** 탭에서 아래 두 가지를 **사용 설정**해요.
   - **Google**: 지원 이메일을 고르고 저장해요.
   - **이메일/비밀번호**

## 4. 데이터베이스 만들기 + 보안 규칙

1. 왼쪽 메뉴에서 **빌드 → Firestore Database → 데이터베이스 만들기**를 눌러요.
2. 위치는 **asia-northeast3 (서울)**을 추천해요. 이 위치는 나중에 바꿀 수 없어요.
3. **프로덕션 모드**로 시작해요.
4. 만들어지면 **규칙** 탭을 열고, 원래 내용을 지운 뒤 `firestore.rules` 파일 내용을 통째로 붙여넣고 **게시**해요.

이 규칙대로라면:
- 공간을 만든 사람과, 초대코드를 입력한 **한 사람만** 들어올 수 있어요. 최대 2명이에요.
- 두 사람 말고는 아무도 기록을 읽거나 쓸 수 없어요.

## 5. 인터넷에 올리기 (배포)

앱 설치와 로그인은 `https://` 주소에서만 돼요. 둘 중 하나를 고르세요.

### 방법 A. Netlify Drop (가장 쉬움, 무료)
1. https://app.netlify.com/drop 에 들어가요. 무료 가입이 필요해요.
2. 이 폴더 **통째로** 드래그해서 놓아요. 그러면 `https://어쩌구.netlify.app` 주소가 생겨요.
3. **중요:** Firebase 콘솔 → Authentication → **설정 → 승인된 도메인 → 도메인 추가**에 `어쩌구.netlify.app`을 넣어요. 이걸 빼먹으면 로그인할 때 "승인 도메인" 오류가 나요.
4. 앱을 고친 뒤 다시 올릴 때는 Netlify 사이트의 **Deploys** 탭에 폴더를 다시 드래그하면 돼요.

### 방법 B. Firebase Hosting (같은 Firebase 안에서 관리)
Node.js가 깔린 PC의 터미널에서 이 폴더로 이동해서 실행해요.
```bash
npm install -g firebase-tools
firebase login
firebase use --add          # 1단계에서 만든 프로젝트 선택
firebase deploy             # 사이트 배포 + 보안 규칙 반영
```
`https://프로젝트ID.web.app` 주소가 생겨요. 이 주소는 승인된 도메인에 자동으로 들어가 있어요.

## 6. 앱 설치하기

- **PC (Chrome/Edge)**: 주소를 열고 주소창 오른쪽 **설치 아이콘(⊕)**을 누르거나, 앱의 설정 → **앱 설치하기**를 눌러요. 바탕화면과 시작 메뉴에 아이콘이 생겨요. 처음 보여주신 `.lnk` 바로가기와 같은 방식이에요.
- **안드로이드 (Chrome)**: 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**
- **아이폰 (Safari)**: 공유 버튼 → **홈 화면에 추가**

## 7. 커플 연결

1. 한 사람이 로그인한 뒤 **새 공간 만들기**를 눌러요. 그러면 8자리 초대코드가 나와요.
2. 상대방에게 코드를 보내요. 설정 → 커플 연결에서 **코드 복사하기**를 누르면 돼요.
3. 상대방은 같은 주소로 들어가 로그인한 뒤, **초대코드가 있다면** 칸에 코드를 넣고 **연결하기**를 눌러요.
4. 연결되면 홈 상단에 "나 ♥ 상대" 이름이 나와요.

## 알아두면 좋은 것

- **사진**: 자동으로 줄여서(최대 1000px, 0.7MB 이하) 데이터베이스에 저장해요. 결제가 필요한 Firebase Storage는 쓰지 않아요. 무료 한도는 저장 공간 1GiB라서 사진 수천 장 정도까지 넉넉해요.
- **오프라인**: 인터넷이 끊겨도 앱이 열리고, 기록한 내용은 다시 연결되면 자동으로 올라가요.
- **알림**: 상대가 기록을 남기면 종 아이콘에 빨간 점이 떠요. 휴대폰 푸시 알림은 넣지 않았어요.
- **기능 요청하기**: 설정에 남긴 요청을 두 사람이 함께 볼 수 있어요.
- **앱을 고친 뒤 다시 배포할 때**는 `sw.js` 맨 위의 `VERSION`(예: `woori-v1` → `woori-v2`)을 올려주세요. 그래야 설치된 앱도 새 버전으로 바뀌어요.
- **체험 모드에서 쓴 기록**은 Firebase로 옮겨지지 않아요.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 로그인 시 "승인 도메인에 없어요" | 5단계 A-3: 배포 주소를 승인된 도메인에 추가 |
| "로그인 방식이 꺼져 있어요" | 3단계: Google·이메일 로그인 사용 설정 |
| "공간을 만들지 못했어요" / "권한이 없어" | 4단계 보안 규칙을 붙여넣고 **게시**했는지 확인 |
| 계속 "체험 모드"로 나옴 | `firebase-config.js`에 값을 넣고 저장 → 다시 배포 → 앱 새로고침 |
| 고쳤는데 옛날 화면이 나옴 | `sw.js`의 VERSION 올려서 배포 후, 앱을 껐다 켜기 |
